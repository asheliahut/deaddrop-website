| Variable | Used by | Same as | Meaning |
| --- | --- | --- | --- |
| `DEADDROP_CONFIG` | all commands | `--config` | Path to the config file |
| `DEADDROP_KEY` | `fetch` | `--key` | Decryption key (`AGE-SECRET-KEY-1...`) for data served with `--encrypt`. An empty value is ignored. |
| `DEADDROP_IDENTITY` | `fetch`, `id` | `--identity`, `fetch.identity` | Identity file a client connects with, for a server's `--allow` |
| `DEADDROP_ALLOW` | `serve` | `--allow`, `serve.allow` | Comma-separated client ids allowed to download |
| `DEADDROP_EXPIRE_AFTER` | `serve` | `--expire-after`, `serve.expire_after` | How long each ticket works after it's printed, e.g. `24h` |
| `DEADDROP_NOTIFY` | `serve` | `--notify` | Comma-separated notifiers, e.g. `discord=https://...,webhook+key=https://...` |
| `DEADDROP_RESET_TOKEN` | `serve`, `reset` | `--reset-token`, `--token` | Reset token |
| `DEADDROP_NO_PROGRESS` | all commands | `--no-progress`, `progress = false` | `true`: plain progress lines, no bars |
| `NO_COLOR` | all commands | | Set: no colors in progress bars or log lines |
| `CLICOLOR` | all commands | | `0`: no colors |
| `CLICOLOR_FORCE` | all commands | | `1`: force colors on |
| `TERM` | all commands | | `dumb`: no progress bars and no colors |
| `RUST_LOG` | all commands | `log` in the config file | Log filter, e.g. `info` or `deaddrop=debug,librqbit=info`. `off` disables logging. |

Precedence: **command-line flag > environment variable > config file > default**.

Values of the secret variables (`DEADDROP_KEY`, `DEADDROP_NOTIFY`,
`DEADDROP_RESET_TOKEN`, `DEADDROP_CONFIG`) are hidden from `--help` output.
Prefer them over flags so secrets stay out of shell history and `ps`.
