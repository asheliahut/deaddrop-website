## Homebrew

[Homebrew](https://brew.sh) (macOS and Linux, Intel + ARM) is the easiest way
to install:

```sh
brew install asheliahut/tap/deaddrop
```

That one command adds the [`asheliahut/tap`](https://github.com/asheliahut/homebrew-tap)
tap and installs the prebuilt release binary (the static musl build on Linux).
You also get:

- bash, zsh and fish [completions](/docs/guides/completions/), loaded
  automatically, with no extra setup
- the example config at `$(brew --prefix)/share/deaddrop/config.example.toml`
- no Gatekeeper prompt on macOS. The release binaries aren't notarized, but
  Homebrew doesn't quarantine what it installs.

The tap updates on every stable release:

```sh
brew upgrade deaddrop                                  # update
brew uninstall deaddrop && brew untap asheliahut/tap   # remove
```

## Prebuilt binaries

Prebuilt binaries are attached to every
[GitHub release](https://github.com/asheliahut/deaddrop/releases), together
with a combined `SHA256SUMS` file:

| Platform | Targets |
| --- | --- |
| Linux (glibc) | `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu` |
| Linux (static musl) | `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl` |
| macOS | `aarch64-apple-darwin` (Apple Silicon), `x86_64-apple-darwin` (Intel) |
| Windows | `x86_64-pc-windows-msvc`, `aarch64-pc-windows-msvc` |

Archives are named `deaddrop-<version>-<target>.tar.gz` (`.zip` on Windows)
and contain the binary, `README.md`, `config.example.toml` and `LICENSE`.

<Tabs syncKey="os">
<TabItem label="Linux">

```sh
VERSION=v1.0.0
TARGET=x86_64-unknown-linux-musl   # static build; or aarch64-unknown-linux-musl, *-linux-gnu
curl -LO "https://github.com/asheliahut/deaddrop/releases/download/$VERSION/deaddrop-$VERSION-$TARGET.tar.gz"
tar -xzf "deaddrop-$VERSION-$TARGET.tar.gz"
sudo install "deaddrop-$VERSION-$TARGET/deaddrop" /usr/local/bin/
```

</TabItem>
<TabItem label="macOS">

```sh
VERSION=v1.0.0
TARGET=aarch64-apple-darwin        # or x86_64-apple-darwin on Intel
curl -LO "https://github.com/asheliahut/deaddrop/releases/download/$VERSION/deaddrop-$VERSION-$TARGET.tar.gz"
tar -xzf "deaddrop-$VERSION-$TARGET.tar.gz"
sudo install "deaddrop-$VERSION-$TARGET/deaddrop" /usr/local/bin/
```

</TabItem>
<TabItem label="Windows">

```powershell
$v = "v1.0.0"
$t = "x86_64-pc-windows-msvc"      # or aarch64-pc-windows-msvc
Invoke-WebRequest "https://github.com/asheliahut/deaddrop/releases/download/$v/deaddrop-$v-$t.zip" -OutFile deaddrop.zip
Expand-Archive deaddrop.zip -DestinationPath .
# then move deaddrop-$v-$t\deaddrop.exe somewhere on your PATH
```

</TabItem>
</Tabs>

### Verify the download

Each archive has a `.sha256` file next to it, and `SHA256SUMS` lists them all:

```sh
curl -LO "https://github.com/asheliahut/deaddrop/releases/download/$VERSION/SHA256SUMS"
sha256sum --check --ignore-missing SHA256SUMS     # macOS: shasum -a 256 -c --ignore-missing SHA256SUMS
```

### Verify build provenance

macOS and Linux tarballs carry signed
[build provenance](https://docs.github.com/en/actions/security-for-github-actions/using-artifact-attestations)
proving they were built by the deaddrop repo's release workflow. Verify one
with the [GitHub CLI](https://cli.github.com):

```sh
gh attestation verify "deaddrop-$VERSION-$TARGET.tar.gz" --repo asheliahut/deaddrop
```

<Aside type="caution" title="macOS Gatekeeper">
	A binary downloaded through a browser is quarantined, and Gatekeeper will
	block it. Use Homebrew or `curl` (neither quarantines), or clear the flag:
	`xattr -d com.apple.quarantine ./deaddrop`.
</Aside>

## From source

You need [Rust](https://rustup.rs) 1.95 or newer (deaddrop uses the 2024
edition):

```sh
cargo install --locked --git https://github.com/asheliahut/deaddrop
```

Or clone and build:

```sh
git clone https://github.com/asheliahut/deaddrop
cd deaddrop
cargo build --release --locked
./target/release/deaddrop --version
```

<Aside>
	Release builds log nothing by default. See [Logging](/docs/guides/scripting/#logging)
	to turn logs on.
</Aside>
